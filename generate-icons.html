Icon Generator for Familia Finanças PWA

This page helps you generate the required icon files for the PWA.

Instructions:

  1. Download the SVG icon above (icon.svg)
  2. Use an online tool like RealFaviconGenerator or Favicon Generator
  3. Upload the SVG and generate PNG icons (192x192 and 512x512)
  4. Save them as icon-192x192.png and icon-512x512.png in the same folder as this app

Alternative:

You can also use the following base64 encoded simple icons:

icon-192x192.png (Base64)

icon-512x512.png (Base64)

Note: For production, it's recommended to create proper icons using a design tool.
